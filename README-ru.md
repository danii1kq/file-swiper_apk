# 🗂️ FileSwiper

**Файловый «клинер» в стиле Tinder для Android.** Свайп вправо — оставить, влево — удалить, вверх — отложить. Освобождайте гигабайты за минуты, а не за часы.

## 📖 О приложении

Разбирать галерею скучно — FileSwiper превращает это в игру.
Выберите, что чистить (фото, видео, аудио, документы), выберите режим — и свайпайте файлы, как в Tinder. Файлы, отправленные «влево», попадают во встроенную **Корзину**, где вы в последний раз всё проверяете перед безвозвратным удалением.

> ⚡ С устройства ничего не удаляется, пока вы не нажмёте **«Удалить навсегда»** в Корзине.

## ✨ Возможности

| | Возможность | Описание |
|---|---|---|
| 🖼️ | **Четыре типа файлов** | Фото · Видео · Аудио (`.mp3`, `.wav`) · Документы (`.doc`, `.docx`, `.xls`, `.xlsx`, `.ppt`, `.pptx`, `.pdf`, `.txt`) |
| 📅 | **Режим «По месяцам»** | Файлы сгруппированы по месяцам; полностью очищенные месяцы получают ~~зачёркнутую~~ отметку — прогресс видно с первого взгляда |
| ⚡ | **«Быстрый режим»** | Перемешивает все выбранные файлы и выдаёт случайную подборку из **5–30** штук (слайдер) |
| 👆 | **Свайп-жесты** | ➡️ вправо = **Оставить** · ⬅️ влево = **Удалить** · ⬆️ вверх (или кнопка «Пропустить») = карточка уходит в **конец очереди** |
| 🃏 | **Богатые карточки** | Живые превью фото/видео, цветные бейджи **Word / Excel / PowerPoint / PDF / TXT** у документов, **Play/Pause с полосой прогресса** у аудио |
| 🗑️ | **Экран Корзины** | Прокручиваемый список с иконками и размерами, счётчик освобождаемого места и безвозвратное удаление через `MediaStore` (с системным диалогом подтверждения на Android 11+) |
| ✈️ | **Лёгкие анимации** | Карточки улетают при лёгком касании — низкие пороги, «пружинное» появление, штампы KEEP/DELETE проявляются по мере свайпа |
| 🎨 | **3 темы** | Как в системе (по умолчанию) · Светлая · Тёмная |
| 🌐 | **2 языка** | Русский (переключается «по умолчанию» — английский) — смена языка прямо в приложении, без перезапуска |

## 🔄 Как устроен сценарий

```
┌──────────────┐   типы файлов + режим          ┌──────────────┐    очередь пуста / назад    ┌──────────────┐
│    Setup     │ ─────────────────────────────> │    Swipe     │ ──────────────────────────> │    Trash     │
│  (настройка) │                                │   сессия     │                             │ проверка +   │
└──────────────┘                                └──────────────┘                             │ удалить ∞    │
        ^                                                                                     └──────────────┘
        │                        «Готово» возвращает сюда                                              │
        └─────────────────────────────────────────────────────────────────────────────────────────────┘
```

1. **Настройка** — отметьте типы файлов, выберите «По месяцам» или «Быстрый режим», при запросе выдайте доступ к хранилищу.
2. **Свайп-сессия** — свайпайте очередь; в шапке видно оставшееся количество, месяц (в режиме по месяцам) и текущий объём корзины.
3. **Корзина** — просмотрите всё, что отправлено на удаление, посмотрите общий объём, затем удалите навсегда. Зелёный экран успеха покажет, сколько места освобождено.

## 🛠️ Технологии

| Слой | Выбор |
|---|---|
| Язык | **Kotlin 1.9.22** |
| UI | **Jetpack Compose** (BOM 2024.01.00) + **Material 3** |
| Архитектура | **MVVM** — пакеты `data` / `ui` / `viewmodel` |
| DI | Ручной DI через `FileSwiperApp` + `AppContainer` (без фреймворков) |
| Навигация | `navigation-compose` (setup → swipe → trash) |
| Доступ к файлам | `MediaStore` + `ContentResolver` (превью через `loadThumbnail`) |
| Аудио | Обёртка над `MediaPlayer` с состоянием воспроизведения |
| Хранение настроек | `SharedPreferences` (тема, язык, очищенные месяцы) |
| min / target SDK | 26 (Android 8.0) / 34 (Android 14) |
| Java-инструменты | target Java 17, Gradle Wrapper **8.7**, AGP 8.2.2 |

## 🔐 Разрешения

| Разрешение | Зачем |
|---|---|
| `MANAGE_EXTERNAL_STORAGE` | Android 11+: полный доступ к файлам (все медиа + документы) через системный тумблер «Доступ ко всем файлам» |
| `READ_MEDIA_IMAGES` / `READ_MEDIA_VIDEO` / `READ_MEDIA_AUDIO` | Android 13+: чтение медиа без широкого тумблера |
| `READ_EXTERNAL_STORAGE` (≤ Android 12) | Классическое рантайм-разрешение на чтение |
| `WRITE_EXTERNAL_STORAGE` (≤ Android 9) | Классическое рантайм-разрешение на запись |

Приложение проверяет доступ при запуске и показывает понятный диалог с переходом в нужный экран системы. Удаление медиа на Android 11+ идёт через `MediaStore.createDeleteRequest` — **системный** диалог подтверждает удаление, никаких «тихих» удалений.

## 🏗️ Сборка

### Требования
- **JDK 17+** (проверено на JDK 21)
- **Android SDK** с платформой **android-34** и build-tools **34.0.0**
- Файл `local.properties` в корне проекта с путём к SDK:

  ```properties
  sdk.dir=C\:\\Path\\To\\Android\\Sdk
  ```

### Сборка debug-APK

```bash
# Windows
.\gradlew.bat assembleDebug

# Linux / macOS
./gradlew assembleDebug
```

Результат появится здесь:

```
app/build/outputs/apk/debug/app-debug.apk
```

Установка на устройство/эмулятор:

```bash
adb install -r app\build\outputs\apk\debug\app-debug.apk
```

### Android Studio
Проект — обычный Gradle: откройте корневую папку в Android Studio, и он импортируется автоматически. (Приложение собрано **без** Android Studio — достаточно Gradle Wrapper.)

## 📌 Примечания и ограничения

- Аудио ограничено `.mp3` / `.wav` (как задумано), сканируются только файлы, видимые `MediaStore`.
- Месяц помечается «очищенным» относительно выбранного набора типов — если вычистить июль только по фото+видео, июль не отметится для документов.
- Сессия «По месяцам» стартует с самого нового неочищенного месяца; можно тапнуть по конкретному месяцу и начать с него.
